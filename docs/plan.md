# AIDoc 开发计划

## 当前阶段目标

当前阶段聚焦稳定的文档编辑和 AI 上下文问答：

1. 文档树和 block 编辑稳定可用
2. 新建、编辑、排序、删除 block 能可靠持久化
3. AI 对话支持引用当前文档或拖拽内容作为上下文
4. 代码执行、图表、白板和文件能力保持独立，不影响文档保存事务

## 不在当前阶段实现的内容

当前阶段不实现额外派生内容构建流程。相关能力后续需要时应重新设计，且必须与正常文档编辑事务解耦。

## 验证重点

- 删除 block 后刷新不会恢复
- 批量保存只保留当前文档传入的 block 列表
- 文档上下文问答不写入派生表
- 后端启动不依赖额外数据库扩展
- 测试覆盖文档和 block 的创建、更新、删除、排序、批量保存
