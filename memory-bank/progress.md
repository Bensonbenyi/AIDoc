# Progress

## 当前状态

AIDoc 当前阶段实现文档编辑、AI 对话、代码执行、图表、白板和文件能力。后端使用 FastAPI + SQLAlchemy async + PostgreSQL，前端使用 Next.js + React + Zustand。

## 当前决策

- 正常文档编辑、保存、删除流程只操作文档和 block 业务表
- AI 问答使用前端引用内容和当前文档内容作为上下文
- 不在当前阶段实现额外派生内容构建流程
- 后续如果需要相关能力，应重新设计为独立流程，避免接入编辑事务

## 最近修复

- 删除 block 后立即保存，避免用户删除后立刻刷新导致内容恢复
- 删除 block 时同步清理白板、图表、文件和代码执行等关联记录
- 移除旧派生内容处理相关代码、配置、依赖和示例内容
